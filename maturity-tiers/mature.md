Darker themes and more visceral combat description are permitted —
real wounds, real danger, morally ambiguous or disturbing subject
matter (grief, trauma, body horror, torture implied off-screen) can be
narrated with genuine weight rather than softened. Strong profanity in
dialogue is fine.

Sexual content is still never permitted, regardless of this tier —
romantic content still fades to black or is omitted entirely, the same
as every other tier. This project does not design or ship tiers aimed
at eliciting explicit sexual content, at any rank.
