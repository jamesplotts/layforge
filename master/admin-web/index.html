    Character templates for this campaign

    What this tab is for: a Host stocks a shelf of ready-made characters here. When a player joins this campaign, one of their options — next to "import my own" and "roll a new one" — is to pick one of these. Picking a template copies it into a fresh character owned by that player; the template on this shelf is never touched, so the same one can be handed to several players. It's the no-prep way to get a new or trying-it-out player into the game with a sensible sheet.

    Discord login
    
      
    
        Optional. Fill in all three fields to give players a "Log in with Discord" button
        (design doc §6.6). Leave them blank to run with no accounts — joining
        works exactly as it does now. The client secret is stored on this Master and shown only
        on this local panel — it is never sent to a player.
      
    
      
    
        How to get these values from Discord (step by step)
        
      
          
    1. 
            Open discord.com/developers/applications
            and click New Application. Name it (e.g. “Layforge – My Table”),
            accept the terms, and click Create. You do not need a bot or a bot token.
          
      2. 
          
    2. 
            On General Information, copy the Application ID —
            paste it into Discord Client ID below.
          
      3. 
          
    3. 
            In the left sidebar click OAuth2. Under Client Secret
            click Reset Secret, confirm, and copy the value (Discord shows it only once
            — if you lose it, reset again). Paste it into Discord Client Secret below.
          
      4. 
          
    4. 
            Still on the OAuth2 page, under Redirects click
            Add Redirect and paste the URL shown below the Redirect URL field.
            Scroll down and click Save Changes.
          
      5. 
          
    5. 
            Paste that same URL into Discord Redirect URL below, then
            Save & Restart. The two must match exactly — scheme, host, port,
            path, no trailing slash.
          
      6. 
        
    
        
    
          Ignore the “OAuth2 URL Generator” and “Scopes” section in the portal
          — Master builds its own sign-in URL (it asks only for the identify scope).
          Discord allows a plain http:// redirect for localhost; a public
          deployment needs https://.
        
    
      
    
      
      
      
      
    
        The host and port here must be exactly what a player types in their browser to
        reach the Layforge client — scheme, host, port, all identical. After a
        player approves on Discord, Discord sends their browser to this URL, so
        localhost only works when the player is on this same machine. On a LAN use
        this Master's LAN IP (e.g. http://192.168.1.5:8080/auth/discord/callback);
        publicly, your domain over https://. The same string must be registered in
        the Discord portal (step 4) and saved here.
